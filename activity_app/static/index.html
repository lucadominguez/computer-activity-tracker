A LOCAL RECORD, NOT A CLOUD SERVICE

You keep the data.

The recorder writes to SQLite on this computer. The dashboard connects only to its loopback address. There are no analytics, external fonts, account services, or automatic uploads.

What is recorded

  • Focused window titles and application names
  • Start and end times of each interval
  • Aggregate key-release counts
  • Away-from-keyboard intervals

Window titles can contain document names, websites, and other sensitive information. Pause before work you do not want recorded.

What is not recorded

  • The characters you type
  • Screenshots, screen video, or audio
  • Clipboard contents or document contents
  • Website URLs beyond text in a window title

This app does not infer productivity, attention, or intent from a focused window.

Pause detaches input monitoring and survives a restart. Resume explicitly when you want to record again. Quit stops the recorder and local server. Closing this browser tab does not quit the tracker.

Use Export to download the selected day with the current timeline filters. CSV is spreadsheet-safe; JSON preserves the original title text. Exports can contain sensitive history. The database is not encrypted by this app; use your operating system's disk encryption.

No delete-history button is exposed to the browser. To remove local history, quit the tracker and manage the database file yourself after making any backup you want to keep.
