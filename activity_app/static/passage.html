Access History

Inspectable by design

Passage records a receipt here before selected text is released to the handoff dialog, and before any context inference call. Copying it to another app is your choice.

Screenshots stay in the local vault. Handoffs and inference calls carry text, source IDs and the endpoint that answered, never image data.

● No external agent access enabled

These are local receipts: what this app prepared or sent. They are not evidence that another app read your history.

Capture & privacy

Screen contents can include sensitive information. Excluded apps, matching window titles and detected password fields are skipped before capture. Password detection depends on the app exposing accessibility information.

Storage and compatibility

New images and text use AES-256-GCM. On Windows, the key is protected by your user account with DPAPI. Timestamp, ID and size envelopes are not encrypted. The original activity database remains unchanged and is not encrypted.

This is a Windows adaptation of Sid’s Passage. Visual similarity search and Memory Lens from the Mac version are not included. Screenshots are never sent anywhere. Text leaves this computer only through the optional context inference below, and only when you click Infer context.

Context inference (optional)

Off by default, and it runs only when you click Infer context on a moment or session. It sends the text read from up to 20 chosen moments together with their window titles, app names and timestamps to the endpoint below. Screenshots, file paths and window positions never leave this computer. Every call is receipted in Access History, and the inferred result is stored encrypted on this computer.

Use an https address, or http only for 127.0.0.1 if you run a model on this computer. The address is not verified as trustworthy.
